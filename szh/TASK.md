# OAPT_A 任务索引

版本：5.0.0；2026-10-17。`szh/` 专用于 OAPT_A“攻击样本生成”D1–D50；其他任务使用其他工作区。

本文件管理全部五十日任务的顺序、入口和验收导航。每天的详细实现放在 `docs/tasks/DNN.md`，实际运行记录放在 `records/DNN/<run-id>/`；正式状态只在共享 Excel 更新，避免同时维护两套进度。文件名 `TASK.md` 是本项目约定，由 [AGENTS.md](AGENTS.md) 明确引导读取。

## 执行入口

1. 读取 [公共规范](../AGENTS.md)、[工作区规范](AGENTS.md)、[执行流程](docs/workflow.md)，打开共享 Excel 与需要核对的四个 DOCX。
2. 用户指定 Dn 时进入对应日文档；用户授权继续 A 计划但未指定日时，从 Excel 找最早尚未验收完成的一日。不能因打开本索引就自动开始任务。
3. 按日文档实现、测试、留证、回填并重新打开校验 Excel，再写交接。文档模板和路径存在不能代替实际执行。

## 来源与排期

四个原始 OAPT DOCX 是计划依据；共享 [进度工作簿](../OAPT_研究方案进度管理_三人员分表与总览甘特图.xlsx) 的 `A_核心算法` 是正式进度入口。工作簿 A:N 为源计划，只回填授权的 O:U；Dn 对应 A 表 n+4 行、总览 n+5 行。来源清单、字段快照和机器索引见 [manifest](docs/tasks/manifest.json)。

个人排期从 2026-10-19 至 2026-12-25，每周五个工作日，周末不计入 Dn。统一方案十三周与个人十周路线的冲突仍待导师确认，不擅自重排。周三/周四二选一讨论及周日复盘的实际信息写 Excel 讨论交流节点。
