1. 按来源组整体划分开发/留出，固定分组列表、输入哈希、规则和 seed；不足量如实记录。
2. 选择源计划要求的 20 条开发轨迹；其余冻结为留出，明确不得用于提示、排序或匹配调参。

4. 检查组、原案例、任务、工具和 path 维度潜在交叉，记录无法满足的隔离维度及研究限制。
