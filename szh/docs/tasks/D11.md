## 本日实施步骤

1. 逐条读开发轨迹，保留原始顺序、原文和全部 ID，禁止解析时按内容重新排序或丢消息。
2. 分别输出 request/result/state_delta，绑定 task/resource/call；关联不完整保留 missing_reason。
3. 生成可读逐轮表并保留原记录到输出事件的映射，以便从表回查来源。
4. 运行 20 条开发输入，逐项核对输入/输出消息数和 ID 集合；数据不足时报告实际数。
