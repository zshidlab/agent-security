## 本日实施步骤

1. 按 task_id/resource_id/call_id 关联事件，校验主体、状态版本和必要证据完整性。
2. 对 Contract 逐项判定并输出中文三值决定、evidence_refs、missing_fields 和原因。
3. 冲突或缺观察优先返回 Unknown；只有充分一致证据才完成，明确反证须满足完整性条件。
4. 用 D19 样例及错任务/错资源事件测试，保证检查器不依赖生成器目标或语言承诺。

所有路径均相对 `szh/`；源计划的工程内路径统一加 `algorithm/` 前缀，原文件名保持。源字段 L 指定的正式交付是必需项，其余为实现和验收配套；路径存在本身不等于验收通过。

| 路径 | 内容和验收职责 |
| --- | --- |
| `algorithm/src/check_step.py` | 对应本日步骤的正式产物；保存版本、输入来源和可复核结果；目录类产物须附内部文件清单。 |
| `algorithm/tests/test_d20_check_step.py` | 本日需要实现的行为验收；覆盖下列正常、拒绝/异常与完整性条件。 |
