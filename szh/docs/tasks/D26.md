## 本日实施步骤

1. 每场景只声明二到四个与本地函数对应的工具，写明主体、资源、参数、权限、状态和观察，不开发通用运行平台。
2. 对 read/update 等同名动作说明不同效果与资源语义，登记字段映射及不能类比的部分。
3. 至少一个目标刻意不提供写入或发送工具，作为硬筛选负例；车辆只用虚构状态字典。
4. 生成四个版本化能力文件，逐字段对照实际 Mock 函数并记录兼容性。
